# lang/strings.txt - the words of Folio's interface: tools/mklang.py makes amiga/lang_table.h from it,
# tools/langcheck.py checks the C source against it (both run by tools/test.sh).
# One row per English string, five columns split by a TAB: English (exactly as the C source has it),
# German, French, Spanish, Italian. UTF-8, but only Latin-1 letters (the Amiga's fonts). C escapes
# \n \t \\ allowed. Lines starting "# " are notes; "## title" starts a section (a comment in the table).
# The terms are PDFCraft's, as Acrobat words them in each language (Lesezeichen, Signets, Marcadores,
# Segnalibri; Schwärzen, Biffer, Censurar, Oscura ...).
